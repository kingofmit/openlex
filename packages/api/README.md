# @openlex/api

REST API server for the OpenLex jurisdiction mapping engine.

Part of [OpenLex](https://github.com/kingofmit/openlex) — open-source jurisdiction mapping engine for U.S. law.

## Installation

```bash
npm install @openlex/api
```

## Usage

```typescript
import { createApp } from "@openlex/api";

const app = createApp();
app.listen(3000);
```
